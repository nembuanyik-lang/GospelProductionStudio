Gospel Production Studio - logo files
=====================================

The logo: a cross built from a studio level meter, gold on charcoal.

Colours
  Gold       #D4A843   (darker gold #8A6D2C, light gold #F3D27A)
  Charcoal   #121419
  Off-white  #F3EFE6

Files
  logo-icon.svg              the icon, any size (vector)
  icon-1024.png ... icon-32.png   the icon as pictures (social media, website, WhatsApp profile: icon-1024.png)
  GospelProductionStudio.ico Windows icon (used by the app and the installer)
  logo-full-dark.png / .pdf  icon + GOSPEL PRODUCTION STUDIO, on charcoal (screens, banners)
  logo-full-light.png / .pdf the same for white paper and light backgrounds (flyers, letters)
                             PNGs have a transparent background; PDFs keep the lettering sharp for printing.

Lettering: Inter Display ExtraBold (GOSPEL) and Inter SemiBold, widely spaced (PRODUCTION STUDIO).
Both fonts are free (SIL Open Font License).
